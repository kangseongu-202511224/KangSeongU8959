참가자 전체 화면 전환

대회 시작 전에는 관리자가 참가자의 화면을 직접 전환할 수 있습니다.

``` 그러면 관리자 진행 관리 화면이 다음과 같이 바뀔 거야. 진행 관리 참가자 전체 화면 전환 **① 대회 규칙 화면 표시** **② 8개 기업 소개 화면 표시** **③ 대기실로 이동** **기존 진행 버튼** 다음 라운드 브리핑 시작 · 거래 시작 · 거래 마감 · 결과 공개 · 최종 종료 관리자 화면의 구성 예시 ## ④ 버튼에 실제 서버 기능 연결 단순히 HTML 버튼만 추가하면 작동하지 않아. 관리자 버튼을 Supabase 함수와 연결해야 해. 같은 `admin.html`에서 아래 문구를 검색해. ```javascript $('logoutBtn').addEventListener('click' ``` 그 줄 **바로 위에** 다음 코드를 붙여넣어. // 참가자 전체 화면 전환 document.querySelectorAll('[data-intro-stage]').forEach(btn => { btn.addEventListener('click', async () => { if (busy || btn.disabled) return; const stage = btn.dataset.introStage; const label = btn.textContent.trim(); if (!confirm( `${label}\n\n모든 참가자의 화면을 변경할까요?` )) return; busy = true; document.querySelectorAll( '[data-intro-stage]' ).forEach(button => button.disabled = true); try { const { error } = await client.rpc( 'ei_set_intro_stage', { p_stage: stage } ); if (error) throw error; message('화면 전환 명령 완료: ' + label); await loadGame(); } catch (error) { message('화면 전환 실패: ' + error.message); } finally { busy = false; document.querySelectorAll( '[data-intro-stage]' ).forEach(button => button.disabled = false); } }); });

모든 진행 명령은 Supabase 서버에서 관리자 권한과 현재 단계를 검증합니다.
